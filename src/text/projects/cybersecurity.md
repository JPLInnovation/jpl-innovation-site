## Why cybersecurity

Every robot, drone, and web app we build sits on a network. Knowing how that network is put together, and how it can be attacked, is what lets us keep our projects safe.

This track grew out of infrastructure administration: learning how routers, switches, and servers fit together, first through CCNA-related study and then hands-on training at VnPro academy.

### Networking: CCNA

What we practice:

- Configuring routers and Layer 2 / Layer 3 switches
- IP addressing and subnetting
- VLANs and routing between them
- Static and dynamic routing
- Access control lists (ACLs) to filter traffic
- Securing device access: strong passwords, SSH, and shutting down unused ports

### Windows infrastructure

What we're learning:

- Windows Server roles: Active Directory, DNS, and DHCP
- Managing users, groups, and permissions
- Group Policy to enforce security settings across machines
- How Windows boots, and troubleshooting storage and hardware

### What's next

- A lab network that ties the switches, router, and a Windows server together
- Hardening practice: firewall rules, least-privilege accounts, and patching
- Write-ups of every lab so new members can follow along
